# TinyLedger

シンプルな個人用現金出納記録アプリです。
電子マネーやクレジットカードではなく、「現金のみ」を素早く記録することを目的としています。

DBを使用せず、ブラウザの LocalStorage に保存します。

---

## 概要

財布の現金出入りを最小操作で記録するための単機能アプリです。

「家計簿」ではなく「現金メモ」に近い思想です。

入力例：

- 自販機
- 昼食
- ATM引き出し
- 駐車場
- 小銭利用

---

## 機能

- 残高自動計算
- 金額ボタン入力
- 入金 / 出金記録
- メモ入力
- 履歴表示
- LocalStorage保存
- スマホ向けUI

対応ボタン：

```text
+10000
+5000
+1000
+500
+100
+50
+10
+5
+1

-1000
-500
-100
```

---

## 技術構成

- HTML
- CSS
- JavaScript
- LocalStorage

サーバーサイドDBは利用していません。

## 実行方法

index.html をブラウザで開くだけで利用可能です。

xSERVER例：

```text
/public_html/tools/tiny-ledger/
```

アクセス例：

```text
https://example.com/tools/tiny-ledger/
```
